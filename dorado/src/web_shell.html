What can I do here?

This is a real Cedar 6.1 desktop. Click the CommandTool (the text window on the right) on its bottom % prompt line to give it the keyboard, then type one of these and press Return. Each is also a button in the CommandTool's menu line (beside STOP! / Find) — click it with the left mouse button instead, if you prefer.

Welcome.cm Prints this list inside Cedar itself.
Schematic.cm The Dorado draws its own processor board — the 1979 ProcH “bit slice 07” sheet, scanned at PARC, displayed by the machine it documents.
Sil ProcH01.sil The same board in Sil, PARC's own drawing editor — not a scan but Ed Clark's 1981 vector original, which you can scroll, zoom and edit. Its signal names are the ones this emulator implements: BMux, MemBase, Md, Q.
Moon.cm A 1978 photograph of the moon, halftoned by Cedar's Imager (the quickest picture to paint).
Ifu.cm The Instruction Fetch Unit board drawing.
Memo.cm Ed Taft's 1980 Dorado Booting memo, formatted in Tioga, Cedar's document editor.
Images.cm Fetches the picture collection and lists what's available.

Pictures take a while to appear — the Imager is doing real 1985 halftone work, and the schematics are large. Watch the CommandTool for progress. Everything here is Cedar's own machinery: .cm command files and menu buttons, exactly as PARC's own sample user profiles set them up.

Click the display to give it keyboard focus. In the NetExec menu, type a program name (e.g. Galaxian) and press Return to boot it; or pick one from the dropdown above to boot it directly. F1 pauses/resumes. The middle/right mouse buttons map to the Alto's 3-button mouse. Cmd/Ctrl+V pastes the clipboard as keystrokes — handy for the long Cedar Eval lines.

Pick Cedar 6.1 to boot the real Cedar/Mesa environment from a Pilot disk image instead of the Alto emulator. A saved checkpoint opens directly at the Please login ... / Name: prompt — click the display and type a name, then Return.

Choose Smalltalk-76 to restore a checkpoint of the real Smalltalk-76 system (from PARC's "XM Smalltalk" disk, booted by the Alto Executive's Bootfrom) running on the Dorado's own Smalltalk microcode. It opens at the desktop: Top View, the Classes browser, and a UserView workspace. It is view-only for now: Smalltalk keeps running (its bytecode interpreter is live), but a mouse click derails it — the guest resets the display word task's bank register and the Nova side spins. Wiring up input is the next job.

Choose Interlisp-D Lyric to restore a WebAssembly-native checkpoint at its Exec (XCL) desktop with 204 library packages on disk and a file server behind the {DORADO} device. Click the Exec window and type (IL:FILESLOAD HELPSYS), then (IL:LOAD '{DORADO}<IRM>IRMDEMO) — answer the {DORADO} Login: prompt with Guest twice — and the 1987 Interlisp-D Reference Manual opens to the CAR page, fetched over Leaf, the IFS random-access file protocol. Any (IL:IRM.LOOKUP 'NAME) looks up another entry.

A few Alto games (Pool, Star Wars, Trek; Missile Command past its attract screen) load custom microcode into the Alto's writable control store — hardware the Dorado does not have — so they trap into Swat on a real Dorado and do the same here. They are omitted from the menu (Missile Command still shows its attract screen).
