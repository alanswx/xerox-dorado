Xerox Dorado

PARC research workstation (1978), emulated in your browser — running its native Cedar 6.1 / Mesa environment, plus Alto software via the Dorado's Alto-emulator microcode.

Loading emulator…
Click the display to give it keyboard focus. In the NetExec menu, type a program name (e.g. Galaxian) and press Return to boot it; or pick one from the dropdown above to boot it directly. F1 pauses/resumes. The middle/right mouse buttons map to the Alto's 3-button mouse.

Pick Cedar 6.1 to boot the real Cedar/Mesa environment from a Pilot disk image instead of the Alto emulator. It is a much longer boot (a minute or two) and ends at a Please login ... / Name: prompt — click the display and type a name, then Return.
