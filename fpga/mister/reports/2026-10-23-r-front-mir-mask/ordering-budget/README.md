# MIR clock masking: bounded ordering and source properties

The generated experiment removes the task-priority data calculation from
MIR's clock cone. The original normal Clock0 masks task data on HIGH root
events. During LOW root events, that clock cannot rise, so the task flop's
normal data capture cannot change its output. NoDispatch can still set the
inverted SwitchUp Q asynchronously. A per-wave combinational view preserves
that update's actual epoch; the real task flop and all state remain intact.
No architectural Q, pipeline cycle, reset, initialization or RAM copy is added.

source3110f49e, with an inverse-checked edit list. The maintained command RTL
