## Open arrival gap

A simultaneous root-clock rise and RepeatCur release produces a pulse in the
illustrative original gate model that the settled-level candidate misses.
Both engines reject the combined transition at event 34. Two additional tests
first settle the changed instruction data while the clock remains HIGH; the
subsequent base rise/CBHold release alone still fails at event 35. Both see one
extra edge on the 20 connected MIR clock channels. This isolates a clock-arrival
gap rather than a raw-data transition. It does not prove a pulse of sufficient
width on a physical Dorado board.

The passing matrix separates that root rise from RepeatCur release explicitly.
**Do not extend its passing claim to unrestricted input arrivals or substitute
this evaluator into the native machine.** Connect the original Control-A and
memory phase/hold producers, then establish the actual capture relationship.
No timing exception or invented pipeline stage resolves this issue.

## Original source seams

The selected-boundary audit traces ten unused inputs to unconsumed package
halves and rejects five changes that make them live. It checks 34 ContB pins
and 22 MemC pins, plus the original cross-board drivers:

- CLKEnable'a is the wired OR of ContA k01.14 and k02.15: `!Q9 | Q11`.
  It is distinct from Control-A's internal `Q6 | !Q7` clock enable.
- StartCycle'a is ContA k03.14, `!Q23`; its internal StartCycle' is k04.14,
  `!Q25`. Their original stages must remain distinct.
- rMIRa combines ContA j02.14 and ContB h03.2 on named backplane C177.
- MemC Hold combines e23.Q0, inverted e22.Q0 and inverted e22.Q1 through three
  original wired-OR drivers. Separate d23 outputs fan it out to PRhold, MXHold
  and CBHold. CBHold, Hold and PRhold retain distinct connector paths.
- e22 and e23's A half use PrClk1'Da; e23's B half uses clk1'Dc. These lead
  through j18/i18 to h12's preClk1'D. Their upstream phase and data contracts
  remain unqualified.

## Preserved failures and evidence

The first matrix failed because its CP-selector mutation was not detected:
the preceding test had already set the MIR bits. Clearing through the original
reset before each transaction exposed two candidate errors: BSEL.2 must use
i03.R1 and ALUF.2 must use i03.R2. The failed matrices and intermediate pilots
are preserved alongside the corrected source, rather than relabeled as passes.
