# Post-edge memory readiness: one-board component qualification

The candidate adds an address preview using the original RAS/CAS capture equations and predicts the existing cache-valid, waiting and write-completion state. It evaluates hold and advance readiness before the late machine-step selection. Stored address/data, original board outputs and host request/response acceptance epochs are preserved. The result replaces the long address-to-ready half-cycle path with a registered equivalent; the complete native core is not yet integrated.

The original 144-chip MSA comparison passes 12,012 complete-board cycles and all 9,437,184 stored bits. Its BL8 raw trace, including host timestamps, is byte-identical to the canonical reference: 750 backing reads, 7,872 writes, 1,111 output transitions, 112,849 host cycles. Three compiled runtime controls reject stale ready, old address and omitted write readiness. Separate 8-bit and 12-bit group comparisons pass in Icarus and Verilator: each checks 40,000 host edges, 3,531 machine steps, 1,591 reads, 359 writes, 1,948 responses while paused and 14 reset cycles. The zero initial row/column fixture is explicit and shared with the original oracle. Both simulators reject compiled stale-ready controls.

A full one-MSA fit includes all 16 groups, original board logic, address preview cells and the native altclkctrl global clock gate. Host services are registered virtual ports; the complete CPU, eight-board fanout and physical SDRAM backend/I/O are outside this fit. At 15 ns, all four operating conditions pass: minimum setup +0.121 ns, hold +0.067 ns, minimum pulse +6.547 ns. All setup/hold unconstrained categories are zero. The review covers all 16 logical ready bits and the one physical duplicate of group 14, plus prediction, ready-to-gate and late-step paths. No timing exceptions were added. Resources: 1,520 ALMs, 2,635 registers, no RAM or DSP.

All map/fit/sta/audit stages are terminal with return code zero. Quartus appended only its exact LAST_QUARTUS_VERSION metadata line to the QSF; prepared and fitted hashes plus that exact append are retained. The two missing-source nets are original MC10125 VBB/reference inputs, checked against the primary MSA wire list. Connectivity warnings are confined to unchanged original cells. All 112 constant outputs are exact raw-data bus padding. The other warnings are unused nets, processor count and the Lite LogicLock license notice; no critical warnings or errors are accepted.

The review rejects eight altered receipts: missing corner, negative gate slack, weakened clock with updated hash, missing ready bit, unconstrained input, wrong prediction with updated hash, missing terminal proof and bypassed global gate with updated hash. Original evidence remains unchanged. Frozen executed sources, raw reports/logs/traces and the collector are included; compiled objects and live pack data are excluded. This is component qualification only. No new hardware load, faster measured rate, full native timing, original-firmware boot or rollback qualification follows from it.
